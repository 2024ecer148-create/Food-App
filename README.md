🍴 SVCE Canteen

SVCE Canteen is a simple and responsive food ordering website designed for Sri Venkateswara College of Engineering, Tirupati.

Features

- 🍔 View food items
- 🔍 Search food
- 📂 Filter food by category
- ➕ Select food quantity
- 🛒 Add items to cart
- 💰 Calculate total price
- 📦 Place orders
- 📍 View canteen location
- 📱 Responsive design

Technologies Used

- HTML
- CSS
- JavaScript

Project Files

SVCE-Canteen/
│
├── index.html
├── style.css
├── script.js
└── README.md

How to Run

1. Download or clone the project.
2. Open the project folder.
3. Open "index.html" in a web browser.
4. Browse the menu and add food items to the cart.
